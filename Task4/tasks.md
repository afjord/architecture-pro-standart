# Крупные задачи для планирования (по ADR001 и ADR002)

---

### MVP «Открытие депозитов онлайн»

---

## Интернет-банк

- Реализация UI раздела депозитов
    - список депозитов и ставок (общие / персональные)
    - экран создания заявки
    - экран статуса заявки
- Интеграция с Deposit Platform
    - создание заявки
    - получение статусов    - обработка ошибок
- Интеграция OTP-подтверждения
    - вызов OTP/SMS оркестратора
    - подтверждение / отказ операции
- Обработка деградаций
    - недоступность OTP
    - недоступность Deposit Platform
- Минимизация доработок ядра интернет-банка подрядчика

---

## Сайт банка

- Реализация страницы депозитов для новых клиентов
- Реализация формы подачи заявки (ФИО + телефон)
- Интеграция с Deposit Platform
- Отображение подтверждения принятия заявки
- Обработка ошибок и повторной отправки заявки

---

## Deposit Platform (новый контур)

### Deposit API / Application Service
- Проектирование модели заявки и статусов
- Реализация API создания заявки (идемпотентность)
- Реализация API получения статуса заявки
- Хранение заявок и истории изменений
- Логирование, метрики, алертинг

### Интеграция с АБС
- Реализация ABS Integration Adapter
- Асинхронная передача заявок в АБС
- Получение статусов из АБС
- Реализация ретраев и компенсаций
- Защита АБС от online-нагрузки

### OTP / SMS оркестратор
- Реализация OTP-потока
- Интеграция с SMS-шлюзом банка
- Уведомления клиента о статусах заявки
- Ретраи и контроль доставки SMS

---

## АБС

- Приём онлайн-заявок через интеграционный слой
- Обработка заявок бэк-офисом депозитов
- Подтверждение условий депозита
- Открытие депозита
- Поддержка идентификации в отделении
- Предоставление утверждённых ставок как источника истины

---

## Система колл-центра банка

- Приём заявок новых клиентов
- Отображение информации по заявке
- Консультация клиента и фиксация условий
- Интеграция с Rates API для просмотра ставок

---

### Передача ставок в колл-центры

---

## Rates Service / Rates API

- Проектирование read-модели ставок
- Реализация API чтения общих ставок
- Хранение истории и версий ставок
- Контроль актуальности данных (SLA)
- Мониторинг актуальности ставок
- Синхронизация ставок из АБС
- Обновление read-модели ставок
- Контроль ошибок синхронизации
- Логирование и алертинг

---

## Система колл-центра банка (внутренняя)

- Интеграция с Rates API
- Отображение актуальных ставок в UI операторов
- Обновление сценариев консультации
- Fallback-логика при недоступности сервиса ставок

---

## Rates Exporter (Deposit Platform)

- Проектирование формата файла ставок
- Генерация файлов ставок
- Доставка файлов партнёрскому колл-центру
    - без API
    - без SFTP
    - через согласованный файловый канал
- Контроль успешности передачи
- Ретраи и алертинг при сбоях

---

## Партнёрский колл-центр (со стороны банка)

- Согласование формата файла
- Согласование канала передачи
- Согласование периодичности обновлений
- Процедура подтверждения получения файла
- Операционные инструкции и SLA
